<a href="https://github.com/Aylton-dev/Ecommerce-Microservices">Ecommerce-Microservices</a></h3>

API de e-commerce construída com arquitetura de microsserviços, em que cada serviço é independente e se comunica por um ponto único de entrada.

API Gateway: roteamento centralizado das requisições
Eureka: registro e descoberta dinâmica dos serviços
auth-service: usuários, perfis (roles) e login com JWT e Spring Security
catalog-service: CRUD de categorias e produtos, com verificação de estoque
order-service: criação e consulta de pedidos, validando o estoque no catálogo via OpenFeign

<a href="https://github.com/Aylton-dev/RiotAPIAnalytics">Riot API Analytics</a></h3>

Coleta partidas ranqueadas pela Riot Games API e calcula a taxa de vitória por item, entregando os resultados em uma API REST.

Coleta assíncrona de partidas (Match-V5) com HTTPX, com filtros por campeão, rota e duração mínima
Persistência em SQLite com SQLAlchemy, evitando registros duplicados
Análise com Pandas: agregação estatística da taxa de vitória por item
API REST com os indicadores ordenados, documentada com FastAPI
